## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Module Layout** | Design station module placement and connection planning |
| **Production Calc** | Calculate input and output rates for your planned production setup |
| **Resource Estimator** | Estimate construction cost in credits and resources per plan |
| **Blueprint Save** | Save station design blueprints for later reference or improvement |
